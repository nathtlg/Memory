# Memory

🎮 Jeu de Memory en JS.

## Démo

[Accès au jeu](https://nathtlg.github.io/Memory/)

## Technologies

- HTML5
- CSS3 (CSS Grid et Flex)
- JavaScript ES6
- API Picsum

## Fonctionnalités

- 16 cartes et 8 paires d'images
- Mélange
- Détection des paires
- Chronomètre et compteur de coups
- Réinitialisation de la partie

## Lancement local

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/nathtlg/memory.git
   ```

2. Ouvrir le dossier dans VS Code.
3. Lancer `index.html` avec Live Server.

ou 

Ouvrer index.html sur votre navigateur.
